# Help improve Zumuro

This is a product showcase and community repository. The application source code is private.

Contributions are welcome through bug reports, feature proposals, accessibility feedback, translations, device compatibility observations and discussions. Public pull requests can improve these showcase documents; they do not provide access to application code.

For bugs, include the app/browser version, platform, expected behaviour and reproducible steps. For playback, mention whether the song came from search or a playlist, whether the screen was locked, and whether Bluetooth was involved. Remove personal details from screenshots and avoid private playlist links.

Use [Issues](https://github.com/krishivsurti/zumuro/issues/new/choose) for reproducible bugs and feature requests. Use [Discussions](https://github.com/krishivsurti/zumuro/discussions) for ideas, questions and collaboration proposals.

Never post passwords, tokens, Firebase credentials, account exports or other private information. Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

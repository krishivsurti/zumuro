# Report a security concern privately

Use [GitHub private vulnerability reporting](https://github.com/krishivsurti/zumuro/security/advisories/new) for suspected account-data exposure, authentication issues or other vulnerabilities.

Do not publish personal data, credentials, private links or exploit details in an issue or discussion. Include the affected version, platform, reproduction steps and impact, using accounts you control.

This repository contains showcase materials only. No application source code, backend configuration, Firebase project files, deployment credentials or signing keys are distributed here.

There is no guaranteed response time or claim that the application is free of vulnerabilities. Ordinary playback and interface bugs can use the issue templates with sensitive information removed.
